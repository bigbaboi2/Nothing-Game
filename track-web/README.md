# HD-2D Cozy Riverside Village — Track A (Web / Three.js + WebGL2)

## Chạy nhanh (1 lệnh)
```bash
npm install && npm run dev
```
Mở trình duyệt tại `http://localhost:5173`.

## Chụp toàn bộ bộ ảnh nghiệm thu 1920×1080 (1 lệnh)
```bash
npm run shots
```

## Tái tạo & kiểm tra bảng màu tài nguyên pixel
```bash
npm run assets
```

## Phím tắt tương tác
- `1` / `2` / `3` / `4`: `dawn` / `day` / `dusk` / `night`
- `Q` / `W` / `E`: `clear` / `rain` / `leaves`
- `B`: Bật/tắt Bloom
- `D`: Bật/tắt Tilt-Shift DOF
- `V`: Bật/tắt Volumetric God-Rays
- `R`: Bật/tắt Planar Water Reflection
